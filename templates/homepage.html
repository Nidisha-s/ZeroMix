Zeromix is an AI-assisted smart waste detection system that verifies waste segregation using image analysis and QR-based household identification, promoting rewards for clean practices and accountability for violations.

How Zeromix Works

Waste Image Upload

The worker uploads an image of the collected waste for verification.

AI Waste Detection

A pre-trained AI model analyzes the image to detect visible mixed waste.

Household Mapping

The waste record is digitally linked to the corresponding household.

Reward / Warning System

Clean segregation earns rewards, while violations generate warnings or fines.
